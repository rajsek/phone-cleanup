# Coding-agent prompt

> Help me inspect and clean up my own Android phone using this repository. First confirm the selected ADB serial, model, Android/MIUI version, security patch, and current user. Use inspect.sh and read the resulting local inventory. Compare candidates with the UAD Next Generation database and the actual device; explain advertising, analytics, optional features, and essential services separately. Do not treat package names as evidence of malware. Present a small candidate list with feature impact and uncertainties. Wait for my package selection before invoking remove-reviewed.sh; let me enter its confirmation. Preserve unrelated apps and data. Save and inspect before/after records. If an uninstall reports an error but the package disappears, report the inconsistency instead of claiming a clean success. Check visible symptoms separately: saved wallpaper, app notifications, and MIUI's lock-screen panel have different causes. Do not root, reboot, restore apps, accept terms, change wallpaper, or install new apps without my authorization. Do not publish raw inventories, network addresses, pairing codes, or screenshots. Report package-state proof separately from manual phone checks, malware scans, and performance claims.
